About

This page is built in part to demonstrate work for the Charlotte class ITIS3135 - Front-End Web Application Development. Throughout this course, I will learn and practice web development using HTML, CSS, and JavaScript. The course tools include VS Code and Emmet to help write and organize code.

Throughout the semester, I will develop several websites to demonstrate my understanding of web design and development. These projects include a personal site, a course site, and additional websites that will allow me to practice different development techniques.

  • Personal Site: A personal website that introduces me and provides links to my other projects.
  • Course Site: My ITIS3135 website that contains my assignments, coursework, and projects.
  • Crappy Website: A deliberately poorly designed website that demonstrates bad web design practices.
  • Whimsical / Product Company: A creative website based on a fictional company or product.
  • Client Project: A website developed for a client using the skills learned throughout the course.
